# Hospital-management-system
# 🏥 Hospital Management System 

A web-based Hospital Management System developed using PHP, MySQL, HTML, and CSS.  
It allows patients to book appointments with doctors and enables admins to manage doctors and appointments.

# Features

# Patient Side
- Patient registration (`register.php`)
- Patient login/logout (`login.php`, `logout.php`)
- View available doctors (`dashboard.php`)
- Book appointments (`book.php`)
- View personal appointments (`my_appointments.php`)

# Admin Side
- Admin login/logout (`admin_login.php`, `admin_logout.php`)
- Admin dashboard (`admin_dashboard.php`)
- Add doctors (`add_doctor.php`)
- Manage appointments (approve/reject) (`manage_appointments.php`)
- View all appointments (`view_appointment.php`)

# Tech Stack
- HTML
- CSS (`style.css`)
- PHP
- MySQL
- XAMPP (Apache + MySQL)

# Database
Create a database named: `hospital_db`

# Note
- Place project folder inside `htdocs` (XAMPP)
- Start Apache and MySQL before running
- Run project using: `http://localhost/your-folder-name/`
